# Islamic Minimal Live Wallpaper

A beautiful, minimalistic Islamic live wallpaper built with HTML, CSS, and JavaScript.

## Features
- **Dynamic Background**: Stunning visual backdrop with a subtle vignette effect to enhance text visibility.
- **Spiritual Words & Quranic Verses**: Cycles through beautiful Urdu calligraphy of spiritual concepts (like Tawakkul, Sabr, Shukr, etc.) along with corresponding Arabic Quranic verses, translations, and references.
- **Ink Reveal Animations**: Features elegant CSS-based ink draw-in and dissolve transitions.
- **Customizable**: Control the display duration and transition speed of the verses.
- **Responsive & Modern**: Fully responsive layout optimized for a clean, immersive look.

## Technologies Used
- HTML5
- CSS3 (Variables, Flexbox, Animations, Glassmorphism, Filters)
- Vanilla JavaScript
- Google Fonts (`Amiri`, `Cinzel`, `Noto Nastaliq Urdu`)

## How to use
- If you use Lively Wallpaper in windows just add this folder to the Lively Wallpaper and open `index.html` file in the Lively Wallpaper.
